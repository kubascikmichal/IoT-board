\section{MicroPython pre vstavané systémy}

MicroPython je zjednodušená implementácia Pythonu určená pre mikrokontroléry. Poskytuje rýchly vývoj a čitateľný kód priamo na zariadení.

\subsection*{Silné stránky}
- Rýchle prototypovanie, dynamické typy, bohatá syntax Pythonu.
- Rozšírenia pre prácu s GPIO, I2C, SPI, ADC.

\subsection*{Obmedzenia}
- Menej efektívny ako C/C++; obmedzená pamäť.
- Nie všetky knižnice Pythonu sú dostupné.

\subsection*{Nasadenie}
- Použitie na ESP32/ESP8266 a iných mikrokontroléroch.
- Kombinácia MicroPythonu na logike a C pre výkonovo náročné časti.

Pre dokumentáciu a referencie pozri MicroPython docs \cite{micropython_docs}.
